# cursor_feishu

这是飞书对接 Cursor 的测试仓库。

用来验证从飞书发出的需求能否被 Cursor Cloud Agent 接到，并在本仓库里完成代码或文档改动、提交，再开出 Pull Request。

当前用途仅限联调与流程验证，不承载正式业务代码。

## 从飞书发来需求时，我能做什么

需求发到这个仓库后，我会在当前分支里直接改文件，并给出简短中文说明。常见能做的事：

- 读仓库、回答代码或文档相关的问题，并把结论写进文件
- 新增或修改文档、代码、配置
- 在环境里跑命令、检查和测试，再根据结果改
- 提交并推送到当前分支，创建或更新 Pull Request
- 用简短中文说明改了什么、怎么验证

做不到、也不会做的事：代替你登录飞书或改飞书里的消息；处理与这个仓库无关的外部系统；执行未授权的破坏性操作。
